# Участие в разработке

Начните с [README](README.md), [описания сборки](docs/build.md) и [проверок](docs/validation.md).

В Issues укажите платформу, версию, шаг воспроизведения и текст ошибки. Приложите обезличенный диагностический отчёт, если он нужен для воспроизведения. Не добавляйте профили браузера, cookies, пароли, токены, коды входа или личные чаты.

Изменения расширения проверяются быстрыми тестами и интеграцией на локальных образцах страниц. Изменение runtime требует нового теста совместимости. Проверка в Chrome на Windows не считается подтверждением запуска на Mac.

В Git хранятся исходники и небольшие обезличенные результаты. Готовые архивы с браузерами размещаются в Releases.
