# Проверки Windows 0.14.1

Проверки выполняются локально, без входа в Claude или Gemini.

```powershell
node tests/extension.test.cjs
node tests/comparison.test.cjs
node tests/windows.test.cjs
node tests/capture.test.cjs
```

Первые три команды используют только стандартные модули Node.js. Для четвёртой нужен Playwright и локальный Chromium. Путь к браузеру задаётся переменной `MINI_TEST_CHROME`; по умолчанию используется установленный Chrome. Все запросы страницы перехватываются и заменяются локальными HTML-образцами. Это проверяет извлечение чатов, но не подтверждает текущую разметку Gemini после реального входа.

Файлы `*-tests.json` содержат результаты последнего запуска. Фикстура `fixtures/runtimes-0.13.1.json` нужна для проверки, что обновление расширения не заменило версии и контрольные суммы трёх браузеров.
