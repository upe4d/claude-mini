Шаг 1 из 7

Оставьте наше рабочее место

Если браузер спросит, какую новую вкладку использовать, нажмите «Оставить» / Keep it.

Браузер может показать запрос об изменении новой вкладки.
Оставить / Keep it

Так новая вкладка будет открывать ваше рабочее место Claude.

Шаг 2 из 7

Закрепите значок расширения

Справа от адресной строки нажмите пазл «Расширения». Найдите Claude mini: Browser.

Chrome / Brave: нажмите булавку рядом с названием.
Edge: включите показ значка на панели инструментов.
Если значок или расширение не появились
  1. Откройте страницу расширений кнопкой ниже.
  2. Включите режим разработчика.
  3. Нажмите «Загрузить распакованное» / Load unpacked.
  4. Выберите папку расширения из поля ниже.
  5. Вернитесь сюда и закрепите значок.

Шаг 3 из 7

Проверьте язык, время и CPU

Ниже — ваши сохранённые настройки. Рекомендуем English · US. Часовой пояс выберите явно.

Выбирайте часовой пояс региона подключения; если используете VPN — его выбранного региона. Германия — Europe/Berlin; Великобритания — Europe/London. Не подставляйте Москву автоматически: Россия не указана в официальном списке доступности Claude. Выбор пояса не меняет фактический регион и не гарантирует доступ.

CPU доступен бесплатно. Физическое оборудование не меняется; некоторые фоновые контексты могут сообщать другие значения.

Получаем сохранённые настройки…

Шаг 6 из 7

Панель отладки — ожидаемая

После открытия Claude с выбранными настройками браузер может показать такую панель:

Claude mini: Browser started debugging this browser Cancel

Это механизм подключения языка, часового пояса и CPU к рабочей вкладке. Оставьте панель включённой, пока нужны эти настройки.

Если нажать Cancel / «Отмена», подключение может прерваться. В таком случае откройте Claude заново через рабочее место.

Шаг 7 из 7

Откройте Claude и проверьте вкладку

  1. Нажмите зелёную кнопку ниже и войдите в свой аккаунт на сайте Claude.
  2. На открытом сайте нажмите закреплённый значок Claude mini.
  3. Нажмите «Обновить» в панели расширения. Посмотрите текущие язык, пояс и CPU рядом с сохранённым выбором.

Для следующего запуска — ярлык нужного браузера или Launch.cmd. Все обычные настройки остаются доступны в рабочем месте.
