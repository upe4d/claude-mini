4 · Начните работу

Открыть Claude

После запуска нажмите значок Claude mini на открытом сайте → «Обновить». Панель покажет текущие значения рядом с сохранёнными.

Браузер может показать панель «started debugging this browser»: через неё расширение подключает параметры вкладки.

Сохранить открытый чат

  1. Дождитесь конца ответа в Claude или Gemini.
  2. Нажмите значок расширения → «Сохранить открытый чат».
  3. Проверьте предпросмотр. Выберите TXT, MD, JSON или PDF.

Сохраняются только загруженные сообщения. Вложения, изображения и скрытые ветки скачивайте отдельно.

Нужна помощь?

Пройдите подготовку ещё раз. Каждый экран содержит одно действие. Если кнопка всё ещё не находится, покажите этот шаг знакомому и попросите помочь.

Техническая информация и перенос настроек

Изменяется окружение отдельной вкладки. Системные часы, IP и физическое оборудование не меняются. CPU остаётся экспериментальной настройкой: отдельные фоновые контексты могут сообщать исходное значение. Изменение параметров не гарантирует доступ к сервису.

При переходе вкладки на другой домен, включая страницу входа Google, расширение снимает подключённые параметры. После входа заново откройте сервис кнопкой рабочего места.

Перед перезагрузкой сохраните черновики. JSON содержит только выбор сервиса, язык, пояс и CPU, без аккаунтов и чатов.
