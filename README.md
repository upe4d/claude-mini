# Claude mini

Бесплатный комплект из отдельного браузера и расширения. Вы открываете рабочее место, выбираете настройки сайта и запускаете нейросеть. Открытый чат можно сохранить в TXT, Markdown, JSON или PDF.

В этом репозитории находятся исходники бесплатной версии, инструкции и скрипты сборки. **Для установки скачивайте готовый комплект из Releases, а не GitHub «Source code».** В исходниках нет самих браузеров и ваших профилей.

### Запуск на Mac

1. Выберите архив **Apple-Silicon** или **Intel**. Тип процессора указан в меню Apple → «Об этом Mac».
2. Распакуйте всю папку и перенесите её, например, в «Документы».
3. Дважды нажмите **«Запустить.command»**. Браузер уже внутри архива; первый запуск проверит и распакует его.
4. Пройдите четыре экрана мастера. Выберите Claude или Gemini, сохраните параметры и откройте сервис из рабочего места.

Нужна **macOS 13 или новее**. Устанавливать Python, Node.js или обычный Chrome для запуска готового комплекта не требуется. Пошаговая инструкция находится в **«Начните здесь.html»** внутри архива. Начальные требования записаны в [описании браузера](macos/runtime-lock.json).

### Запуск на Windows

В полном комплекте 0.13.1 распакуйте ZIP, откройте **Setup.cmd**, выберите браузеры и пройдите мастер. Для следующего запуска используйте созданный ярлык или **Launch.cmd**. Каждый выбранный браузер хранит отдельный профиль. Инструкция находится в [Windows-каталоге](windows/ПРОЧИТАЙТЕ.txt).

Папка `windows/` в Git содержит исходники и описание файлов, **без трёх больших браузерных архивов**. Сам по себе GitHub «Source code.zip» не является полным Windows-установщиком.

## Что можно делать

- Открывать сервис из отдельного рабочего места.
- Выбирать язык, часовой пояс и число логических процессоров, сообщаемое новой управляемой вкладкой. CPU доступен бесплатно и остаётся экспериментальной настройкой.
- Включать или снимать ограничение непроходящих через прокси UDP-соединений WebRTC в этом профиле.
- По нажатию на значок расширения смотреть измеренные параметры открытой вкладки рядом с её сохранённым выбором.
- Сохранять и переносить настройки через JSON.
- Скачивать загруженные на странице сообщения чата. Для PDF открывается печать: в ней выбирается «Сохранить как PDF».

Настройки новой вкладки описаны в [конфигурации расширения](macos/extension/config.js). Список поддерживаемых сервисов и границы адресов находятся в [services.js](macos/extension/services.js), чтение параметров — в [current.js](macos/extension/current.js), экспорт — в [capture.js](macos/extension/capture.js).

## Что проверено

Для macOS-комплекта проверены целостность архивов, права исполнения `.command`, 40 сценариев запуска с подставными macOS-командами и 26 интеграционных сценариев расширения в настоящем Chrome на Windows. Интеграция использовала локальные образцы страниц, без авторизации в сервисах.

**Нативный запуск на Mac ещё не подтверждён.** Gatekeeper, Связка ключей, вход в реальные аккаунты и актуальная авторизованная разметка Gemini остаются проверкой тестировщика. Это причина отметки предварительного выпуска.

## Где находятся данные

В готовом macOS-комплекте отдельный браузер хранится в `Data/Browser`, настройки и входы — в `Data/Profile`. Не отправляйте папку профиля в Issues и не добавляйте её в Git.

При ошибке запустите **«Диагностика.command»**. Отчёт содержит состояние запуска и версии; он не читает cookies, пароли или содержимое чатов. Приложите TXT и снимок ошибки. Код отчёта открыт в [Диагностика.command](macos/Диагностика.command).

## Ограничения

- Параметры применяются к новой вкладке, открытой кнопкой расширения. Системные часы, IP и физическое оборудование не меняются. Некоторые фоновые контексты могут сообщать исходное значение CPU.
- Экспорт сохраняет только сообщения, загруженные в DOM страницы. Полнота истории не подтверждается; вложения, изображения и скрытые ветки отдельно не скачиваются. Если разметка сайта не распознана, экспорт сообщает об ошибке.
- Ограничение WebRTC может влиять на звонки. Его можно снять в рабочем месте.
- В macOS-комплекте закреплён Chrome for Testing **156.0.8078.47**. Он не обновляется автоматически. В проверенной 157 команда часового пояса была недоступна расширению; переход на другой runtime требует повторного теста совместимости.
- Программа не предоставляет аккаунт, подписку, VPN или гарантию доступа к внешнему сервису.

Исходники сгруппированы по платформам: `macos/` и `windows/`. Скрипты не требуют React или сборщика интерфейса: страницы расширения написаны на HTML, CSS и JavaScript, запуск — Bash для macOS и PowerShell для Windows.
