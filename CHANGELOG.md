# История изменений

Здесь перечислены изменения, подтверждённые опубликованными исходниками и результатами проверок. Номера Windows и macOS описывают разные комплекты: обновления одной платформы не считаются автоматически перенесёнными на другую.

## 0.14.0 — macOS, предварительный выпуск

Подготовлено 7 ноября 2026 года. Нативная проверка Mac ожидается.

### Добавлено

- Самостоятельные комплекты для Apple Silicon и Intel с браузером внутри каждого архива.
- Запуск двойным щелчком через `Запустить.command`, без установки Python, Node.js и обычного Chrome.
- Четыре экрана подготовки: закрепление расширения, выбор параметров, WebRTC и переход в рабочее место.
- Выбор Claude или Gemini в общем интерфейсе. Для сервисов разрешены точные HTTPS-хосты; произвольные сайты и страница входа Google в каталог не входят.
- Отдельный DOM-адаптер экспорта для Gemini, подписи ролей соответствующего сервиса и удаление query/hash из адреса чата в экспорте.
- Диагностика запуска для тестировщика, не читающая содержимое профиля.

### Исправлено

- Кнопка сохранения показывает состояние записи и явное подтверждение «Выбор сохранён».
- Изменения выбора относительно предыдущего запуска того же сервиса выделяются красным.
- Панель сравнивает открытую вкладку с её конфигурацией, а не с текущим глобальным выбором другого сервиса. Без точки сравнения положительное подтверждение не показывается.
- После завершённой подготовки холодный перезапуск открывает рабочее место, сохраняя выбор.

### Сохранено бесплатно

Язык, часовой пояс, CPU, WebRTC, параметры открытой вкладки, перенос настроек и экспорт TXT/MD/JSON/PDF. Исследовательские инструменты Pro в комплект не входят.

### Совместимость и проверки

- Закреплён оригинальный Chrome for Testing `156.0.8078.47`, macOS 13.0+. В тесте 157 команда часового пояса была отклонена браузером. Защита браузера не изменялась.
- Проверены SHA-256 и полный CRC ZIP, версия `Info.plist`, архитектура Mach-O и права исполнения `.command`.
- Пройдены 40 сценариев функций запуска в Git Bash и 26 интеграционных сценариев расширения в Chrome на Windows с локальными страницами.
- Отдельно проверены роли и формат экспорта обоих сервисов, сравнение настроек разных вкладок и явный отказ на неподдерживаемых адресах/разметке.
- Запуск на настоящем Mac, системные подтверждения, Связка ключей и реальные авторизованные сайты ещё не подтверждены. PDF проверен как вызов печати, без утверждения о создании файла на Mac.

Основание: [описание runtime](macos/runtime-lock.json), [код запуска](macos/app/portable.sh), [каталог сервисов](macos/extension/services.js), [пределы проверок](docs/validation.md).

## 0.13.1 — сохранённая Windows-версия

- Комплект содержит установку отдельных Chrome, Edge и Brave; браузеры используют отдельные профили.
- Установщик проверяет архивы и исполняемые файлы по размеру, SHA-256 и описанию runtime.
- Запуск использует промежуточную локальную инструкцию; собственную страницу расширение открывает после регистрации и готовности начальных настроек.
- Сохраняются бесплатные настройки языка, пояса и CPU, WebRTC, перенос настроек, показания вкладки и экспорт чата Claude.
- Поддержка Gemini из macOS 0.14.0 в эту Windows-копию не перенесена.

В репозитории сохранены исходники и метаданные этой версии. Крупные `payload/chrome.zip`, `payload/edge.zip` и `payload/brave.zip` не входят в Git; полный пользовательский комплект загружается отдельно.

Основание: [Windows runtime](windows/app/Runtime.ps1), [запуск](windows/app/Launch.ps1), [регистрация рабочего места](windows/extension/startup-runtime.js), [описание браузеров](windows/Browser-sources.txt).
