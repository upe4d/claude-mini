Рабочее место

Claude и Gemini в отдельном браузере

Одна программа для настройки рабочей вкладки и сохранения открытого чата. Аккаунты и подписки оформляются на сайтах сервисов отдельно.

1 · Запуск

Откройте Запустить.command

Сначала распакуйте весь комплект в постоянную папку. Двойной щелчок по Запустить.command открывает отдельный браузер. Его профиль находится в папке Data рядом с программой.

Для первого открытия смотрите файл «Начните здесь.html» в корне комплекта.

2 · Подготовка

Пройдите четыре экрана

Закрепите значок расширения. Если появится запрос о новой вкладке, нажмите Keep it. Выберите Claude или Gemini, язык, пояс и CPU; проверьте WebRTC.

Открыть мастер ещё раз
3 · Работа

Начинайте с рабочего места

В отдельном браузере нажмите ⌘ + T. Сохраните выбор и откройте сервис зелёной кнопкой. Значок расширения → «Обновить» покажет фактические значения открытой вкладки.

При входе через Google параметры снимаются на другом домене. После авторизации заново откройте сервис из рабочего места.

4 · Экспорт

Сохраните открытый чат

Дождитесь ответа. Значок расширения → «Сохранить открытый чат» → предпросмотр → TXT, MD, JSON или PDF. Для PDF выберите «Сохранить как PDF» в окне печати.

Экспорт читает только сообщения, загруженные на странице. Для старых сообщений прокрутите чат вверх и повторите. Изображения, вложения и скрытые ветки отдельно не скачиваются. Если сайт изменил разметку, экспорт сообщит об ошибке.

Что делает расширение и зачем нужны разрешения

storage — сохраняет выбранные настройки. Временные копии пяти последних экспортов хранятся только в памяти браузера.

activeTab + scripting — по нажатию читает параметры или сообщения открытой вкладки Claude/Gemini.

privacy — включает или снимает ограничение WebRTC в отдельном профиле.

debugger — подключает язык, часовой пояс и CPU к открытой нами вкладке. Поэтому сверху может появляться панель отладки.

Cloudflare — получает ваш IP только после кнопки проверки подключения. Сохранять чат расширение начинает по вашей кнопке. Cookies и пароли код расширения не считывает. Исследовательского наблюдателя API в этой версии нет.

Системные часы, IP и физическая конфигурация Mac не меняются. Показания отдельных фоновых контекстов могут отличаться. Программа не определяет решения сервисов о доступе или блокировках.

Если что-то не получилось

Значок пропал: пазл «Расширения» → Claude mini: Browser → булавка. Если карточки нет: chrome://extensions → Developer mode → Load unpacked → папка extension из комплекта.

Настройки отличаются: откройте сервис новой вкладкой из рабочего места. Если нажали Cancel на панели отладки, подключение параметров прервано. Сравнивайте выбранные значения с измерением на вкладке, а не с системными настройками Mac.

Нужна помощь с кнопкой: перечитайте текущий шаг мастера. Если кнопка всё ещё не находится, попросите знакомого помочь и покажите ему этот экран.

Удаление: закройте отдельный браузер и удалите папку программы обычным способом. Папка Data содержит входы в аккаунты; сохраните её, если хотите оставить профиль. Обычный браузер на Mac этим комплектом не изменяется.
