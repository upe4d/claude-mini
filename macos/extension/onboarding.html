Шаг 1 из 4

Закрепите значок расширения

Браузер и расширение уже запущены. Справа от адресной строки нажмите пазл «Расширения», затем булавку рядом с Claude mini: Browser.

Если Chrome спрашивает о новой вкладке, выберите «Оставить» / Keep it. Тогда ⌘ + T будет открывать ваше рабочее место.

Не вижу расширение

Нажмите кнопку ниже. Если карточка выключена, включите её. Для ручной установки включите Developer mode → Load unpacked и выберите папку extension внутри распакованного комплекта.

На Mac в окне выбора папки можно нажать ⌘ + Shift + G и вставить путь к папке.

Шаг 2 из 4

Выберите сервис и параметры

Один инструмент работает с Claude и Gemini. Выбор можно изменить позже.

CPU меняет сообщаемое вкладкой число, а не оборудование. Настройка экспериментальная: фоновые контексты могут сообщать исходное значение.

Шаг 3 из 4

Проверьте WebRTC

Ограничение запрещает непроходящие через прокси UDP-соединения в этом отдельном профиле.

Если ограничение мешает звонкам, снимите его. Изменить это можно в любое время в рабочем месте.

Шаг 4 из 4

Всё готово. Откройте рабочее место

Там можно проверить подключение по кнопке, сравнить выбор с предыдущим запуском и открыть Claude или Gemini.

  1. Открывайте сервис зелёной кнопкой рабочего места.
  2. Если появится панель started debugging this browser, это подключение параметров вкладки расширением.
  3. На открытом сайте нажмите значок Claude mini → «Обновить». Так видно, какие значения сообщает вкладка.

В следующий раз запустите Запустить.command. В этом браузере ⌘ + T открывает рабочее место. Вход в аккаунт выполняется на сайте выбранного сервиса.
