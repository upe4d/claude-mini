CLAUDE MINI ДЛЯ macOS · БЕСПЛАТНО · 0.14.0

1. Распакуйте всю папку из ZIP и перенесите в «Документы».
2. Дважды нажмите «Запустить.command». Первый запуск проверит и распакует браузер.
3. Следуйте мастеру в открывшемся браузере. Если нужна помощь, откройте «Начните здесь.html».
4. Выберите Claude или Gemini в рабочем месте, сохраните настройки и откройте сервис.

Нужна macOS 13 или новее. Для M1/M2/M3 и новее используйте архив Apple-Silicon; для Intel — Intel.
Браузер уже внутри архива. Python, Node.js и установленный Chrome для запуска не нужны.
Ваши настройки и входы находятся в Data/Profile. Эту папку никому не отправляйте.
Для сообщения об ошибке запустите «Диагностика.command»: откроется папка с безопасным TXT-отчётом.

Это бесплатная сборка, без исследовательских инструментов Pro.
Проверки на Windows выполнены отдельно от реального теста macOS. Нативный запуск на Mac, его системные подтверждения и вход в сервисы ещё требуют проверки тестировщиком.
Короткий список проверок: app/Проверка для тестировщика.html.

Chrome for Testing не обновляется автоматически. Для обновления браузера нужен новый выпуск.
Программа не предоставляет подписку, аккаунт, VPN или гарантию доступа к внешнему сервису.
