# Обновить страницу Mini на хостинге

Адрес страницы: https://cenpad.ru/claude-mini/index.html.

1. Скачайте **Claude-mini-Hosting-Update-v0.14.1.zip** из [релиза страницы](https://github.com/upe4d/claude-mini/releases/tag/v0.14.1-site).
2. В файловом менеджере хостинга откройте корень сайта `cenpad.ru`, где уже есть папка `claude-mini`.
3. Загрузите ZIP и распакуйте с заменой файлов. Внутри уже подготовлена папка `claude-mini`: создавать ещё одну вложенную папку не нужно.
4. Откройте страницу и нажмите Ctrl+F5; на Mac — Command+Shift+R.

Пакет заменяет `claude-mini/index.html` и включает только scoped-файлы `assets/mini-014.css`, `assets/mini-014-changelog.json`, `assets/mini-0141.css`, `assets/mini-0141-changelog.json`. Обновление накопительное: ставить предыдущий патч 0.14.0 отдельно не нужно. Общие стили, скрипты, страница Pro, прежние загрузки и журнал изменений Windows остаются на месте.

Основная кнопка Windows 0.13.1 остаётся. Рядом добавляется отдельная тестовая Windows 0.14.1 с Claude/Gemini. Mac Apple Silicon и Mac Intel 0.14.0 остаются без изменений; нативная проверка Mac ещё ожидается.

Большие готовые комплекты скачиваются с GitHub Releases. Повторно загружать их на хостинг не требуется.

В `web/claude-mini` сохранены исходники текущей страницы Mini вместе с общими ресурсами для разработки. Готовый ZIP обновления содержит только пять изменяемых файлов. Его нужно применять к существующему сайту, где уже размещена страница Pro.

Этот пакет подготовлен локально. Автоматической установки на cenpad.ru не выполнялось.
