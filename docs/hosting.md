# Обновить страницу Mini на хостинге

Адрес страницы: https://cenpad.ru/claude-mini/index.html.

1. Скачайте **Claude-mini-Hosting-Update-v0.14.0.zip** из [релиза страницы](https://github.com/upe4d/claude-mini/releases/tag/v0.14.0-site).
2. В файловом менеджере хостинга откройте корень сайта `cenpad.ru`, где уже есть папка `claude-mini`.
3. Загрузите ZIP и распакуйте с заменой файлов. Внутри уже подготовлена папка `claude-mini`: создавать ещё одну вложенную папку не нужно.
4. Откройте страницу и нажмите Ctrl+F5; на Mac — Command+Shift+R.

Пакет заменяет `claude-mini/index.html` и добавляет только `assets/mini-014.css` и `assets/mini-014-changelog.json`. Общие стили, скрипты, страница Pro, прежние загрузки и журнал изменений Windows остаются на месте.

На странице появятся отдельные загрузки Windows 0.13.1, Mac Apple Silicon и Mac Intel 0.14.0. Для Mac явно указаны предварительный статус и необходимость проверки на настоящем устройстве. Gemini пока относится к Mac-версии.

Большие готовые комплекты скачиваются с GitHub Releases. Повторно загружать их на хостинг не требуется.

В `web/claude-mini` сохранены исходники текущей страницы Mini вместе с общими ресурсами для разработки. Готовый ZIP обновления содержит только три изменяемых файла. Его нужно применять к существующему сайту, где уже размещена страница Pro.

Этот пакет подготовлен локально. Автоматической установки на cenpad.ru не выполнялось.
