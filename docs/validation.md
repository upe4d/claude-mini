# Проверки и их пределы

Результаты относятся к бесплатному macOS-комплекту 0.14.0, подготовленному 7 ноября 2026 года. Проверки выполнены на Windows. Они не заменяют запуск на настоящем Mac и не подтверждают решения внешнего сервиса об аккаунте.

| Проверка | Подтверждённый результат | Что этим не проверено |
|---|---|---|
| Оригинальные macOS runtime | Полный CRC ZIP, вычисленный SHA-256, версия `Info.plist`, минимальная macOS 13.0, архитектура Mach-O ARM64/x64 | Проверка подписи средствами реального Mac, Gatekeeper, появление окна |
| Функции запуска | 40 сценариев с настоящими функциями Bash и подставными macOS-командами: пути, профиль, блокировки, отказ при повреждении, параметры `open` | Нативное выполнение `ditto`, `codesign`, LaunchServices и Finder |
| Расширение в Windows CfT 156.0.8078.47 | 26 интеграционных сценариев, включая четыре экрана мастера, сохранение, WebRTC, панель, экспорт и холодный перезапуск своего профиля | macOS UI и реальные сервисные аккаунты |
| Локальные страницы Claude/Gemini | Страница сообщает выбранные UTC, en-GB и CPU 4; toolbar-панель читает её значения | Совпадение всех браузерных контекстов, серверная обработка или решения сервиса |

| Разметка Gemini | Адаптер распознаёт подготовленные DOM-образцы и явно отказывает при неизвестной разметке | Текущая страница после реальной авторизации |
| Готовые ZIP | В каждом 47 файлов, один runtime нужной архитектуры, все SHA и CRC, 55 локальных ссылок, `.command` и Bash с LF и правами 0755 | Результат установки на устройстве другого человека |

## Почему закреплён Chrome 156

В интеграционном тесте Chrome for Testing 157.0.8103.38 вернул ошибку `Timezone override is only available to trusted clients`. Такой ответ был получен и без специального тестового флага работы с toolbar-панелью. В 156.0.8078.47 существующий сценарий применения параметров прошёл.

Разницу подтвердили [исходники Chromium 156](https://chromium.googlesource.com/chromium/src/+/refs/tags/156.0.8078.47/third_party/blink/renderer/core/inspector/inspector_emulation_agent.cc?format=TEXT) и [Chromium 157](https://chromium.googlesource.com/chromium/src/+/refs/tags/157.0.8103.38/third_party/blink/renderer/core/inspector/inspector_emulation_agent.cc?format=TEXT). Оригинальный браузер не изменён; флаги отключения его защиты не добавлялись.

Это выбранная совместимая версия, а не обещание совместимости с любым новым Chrome. Chrome for Testing не имеет автоматического обновления. Перед сменой runtime необходимо повторить интеграцию и обновить [runtime-lock.json](../macos/runtime-lock.json).

SHA-256 runtime вычислены при получении полных HTTPS-загрузок. Это не опубликованные Google цифровые подписи архивов.

## Что ещё проверить на Mac

В готовом архиве находится `app/Проверка для тестировщика.html`. Основные пункты:

1. Распаковка и запуск двойным щелчком на подходящей архитектуре.
2. Системные подтверждения macOS, запуск браузера и появление рабочего места.
3. Сохранение выбора после полного закрытия и повторного запуска.
4. Вход в нужный сервис и сохранность авторизации при перезапуске.
5. Предпросмотр и скачивание своего обычного чата в обоих сервисах.
6. Запуск `Диагностика.command` и создание TXT-отчёта.

В Issues достаточно версии macOS, типа процессора, шага, текста ошибки и диагностического TXT. Профили, cookies, пароли, коды входа и личную переписку не публикуйте.

## Windows 0.14.1: отдельный предварительный выпуск

В 0.14.1 в Windows перенесён выбор Claude/Gemini, общий предпросмотр экспорта и сравнение параметров конкретной вкладки. Исходные браузерные runtime и схема отдельных профилей сохранены из 0.13.1.

Результаты macOS-ветки, приведённые выше, не считаются автоматически повторённой проверкой новой Windows-сборки. Для Windows-порта выполнено отдельное локальное QA:

| Microsoft Edge 156.0.4314.50 | 22 сценария пройдены | Настоящий браузер, локальные ответы вместо сайтов |
| Brave 1.98.60 | 24 сценария пройдены, с замечанием | Включая два сценария честного предупреждения о списке языков |
| Каталог сервисов и границы адресов | 13 сценариев пройдены | Локальная логика расширения |

В Brave список `navigator.languages` в проверенной конфигурации был `[en-GB]` вместо выбранного `[en-GB, en]`. Панель показывает отличие красным; тесты не называют это полным совпадением параметров. То же сокращение списка воспроизведено с исходной 0.13.1; код применения языка в старой и новой сборке побайтно одинаков. Точная внутренняя причина этим тестом не установлена. Обычные первые/повторные запуски выполнены отдельно; полная повторная распаковка всех runtime не выполнялась, использовались исходные извлечённые движки.

Даже успешный запуск на локальном образце не подтверждает авторизацию или актуальную страницу Gemini после входа. Эти действия выполняет тестировщик. [Короткая проверка](windows-0.14.1-test.md) описывает нужные действия без исследовательских процедур.
