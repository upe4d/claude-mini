Первая установка

Как установить
Claude mini.

Скачайте программу и выполните четыре шага. Дополнительно устанавливать Python или Node.js не нужно.

1

Скачайте программу

Выберите Windows или Mac в блоке загрузки ниже. Распакуйте ZIP целиком. Не запускайте файлы прямо из архива.

2

Запустите установку

Windows: дважды нажмите Setup.cmd и выберите браузеры.
Mac: дважды нажмите «Запустить.command» и дождитесь окна браузера. Всё необходимое уже в комплекте.

3

Подключите расширение

В открывшемся браузере следуйте инструкции. Если появится Keep it («Оставить»), нажмите эту кнопку. Через значок пазла закрепите расширение. Если его нет, мастер объяснит, как установить его.

4

Откройте нейросеть

В рабочем месте сохраните язык, пояс и CPU. На Mac выберите Claude или Gemini; в Windows 0.14.1 — тоже оба сервиса. Основная Windows 0.13.1 работает с Claude. Откройте сервис кнопкой программы. На сайте нажмите значок расширения → «Обновить», чтобы увидеть значения вкладки.

Выберите язык и часовой пояс для новой рабочей вкладки. Эти настройки можно изменить позже. Ограничение WebRTC уменьшает прямые соединения браузера без прокси. Если оно мешает звонкам, его можно отключить в настройках.

Если остались вопросы

Нужна помощь?

Нужно ли всем переходить на Windows 0.14.1?

Нет. Это дополнительный тестовый выпуск для проверки Claude и Gemini. Основная 0.13.1 остаётся доступной для работы с Claude. Проверку настоящего входа и текущего интерфейса Gemini выполняет тестировщик.

Где появилась поддержка Gemini?

Claude и Gemini доступны в предварительной macOS 0.14.0 и новой тестовой Windows 0.14.1. Основная Windows 0.13.1 остаётся комплектом для Claude. Для проверки Gemini на Windows выберите дополнительную тестовую загрузку, а не основную кнопку 0.13.1.

Что означает «предварительный выпуск» для Mac?

Архивы, мастер и расширение прошли локальные проверки, но запуск на настоящем Mac и страницы после авторизации ещё проверяются. Тестировщику нужно пройти список внутри архива. Если появилась ошибка, «Диагностика.command» создаст TXT без чтения cookies и переписки.

У меня ещё ничего не установлено. Что скачивать?

Выберите полный комплект своей системы в блоке загрузки. Основная Windows 0.13.1 — для Claude; если хотите проверить Gemini, скачайте тестовую Windows 0.14.1. Обе запускаются через Setup.cmd. Mac-комплект запускается через «Запустить.command». Маленькое исправление нужно только установленной Windows 0.13.0.

Это отдельный браузер или только расширение?

Браузер уже включён. В Windows-комплекте доступны Chrome for Testing, Edge и Brave с отдельными профилями. В Mac-комплекте — один Chrome for Testing нужной архитектуры. Расширение и пошаговая инструкция входят в оба комплекта.

Нужно устанавливать все три браузера?

В Windows можно установить один, два или три браузера. У каждого будет отдельный профиль. Для Mac скачивается один архив — Apple Silicon или Intel — с одним соответствующим браузером.

Будет работать с Desktop, Claude Code или телефоном?

Сейчас есть браузерные комплекты для Windows x64 и macOS 13+. Desktop, Claude Code и телефон они не настраивают.

Что сохраняется при экспорте чата?

Сообщения, загруженные на странице. Если не хватает старых сообщений, прокрутите чат вверх и повторите экспорт. Вложения, изображения и артефакты скачивайте отдельно. Для PDF выберите «Сохранить как PDF» в окне печати.

Для чего выбирать язык, время и CPU?

Язык и часовой пояс задают соответствующие параметры новой вкладки, открытой из рабочего места. CPU здесь означает число логических процессоров, которое сообщает вкладка. Настройки сохраняются для следующих запусков. Системные часы, IP и само оборудование компьютера не меняются. Фоновые обработчики SharedWorker и ServiceWorker могут сообщать исходное число CPU. Браузер может показывать служебную панель отладки.

Что такое WebRTC и зачем его ограничивать?

WebRTC используется для прямых соединений браузера, в том числе для звонков. В Claude mini можно ограничить соединения без прокси в выбранном профиле. Если после включения ограничения перестали работать звонки, отключите его на странице настроек.

Mini даёт аккаунт или гарантирует доступ к Claude?

Нет. Вход, подписка и доступ определяются выбранным сервисом. Mini не включает аккаунт или VPN и не гарантирует отсутствие ограничений.

Не нахожу нужную кнопку. Как получить помощь?

Перечитайте текущий шаг мастера. Если пункт в вашем браузере называется иначе и найти его не получается, попросите знакомого помочь и покажите этот шаг. Также можно написать @creativerelab.
